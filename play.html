1 · The learned world model, running here

Below is not a game engine. Every frame is produced by the 5M-parameter transformer this project trained, running in your browser: you press a key, it autoregressively emits the next authoritative state — every field, one 4-bit digit at a time — and the page draws whatever it emitted. Nothing corrects it. If the model gets the physics wrong, you will see the physics go wrong, which is the honest behaviour for a world-model demo.

All three are the converged 60k-step models — the exact ones behind Table 1. An earlier export silently grabbed the 15k-step run instead; it was caught because the exporter prints the step it loaded.

The port is verified, not asserted. Two separate checks, because they fail for different reasons: the fp16 round trip changes 0 of 2640 / 1680 / 2160 predicted nibbles, and the JavaScript itself was replayed against PyTorch on every exported start state and action — 0 of 2646, 0 of 2133 and 0 of 1314 nibbles differ, digit for digit. If either had been non-zero the page would say so, because a demo that quietly disagrees with the numbers beside it is worse than no demo.

⏱ Roughly 1 second per transition in a browser: each tick is 70–110 sequential decode steps through six transformer layers, in plain JavaScript. Use step to go one tick at a time, or auto-play to let it run. This is a fidelity demo, not a speed demo — the same model runs at thousands of transitions per second on the GPU.

What to look for. Watch the field strip on the right: on most ticks only a handful of the state's digits change. That is the whole reason the COPY token exists — under a plain codec the model has no way to say "unchanged" and must restate every field correctly, which is how it managed to score worse than doing nothing on the 3-D substrate.

Breakout is the delta (COPY) model, whose H32 exactness went 0.656 → 1.000. Asterix is included precisely because it fails: its ceiling at H16 is 0.047, so the environment itself forbids long exact rollouts, and you should be able to watch the state come apart. A page that only showed the winning domain would be advertising, not evidence.

2 · VoxelWorld — the simulator, in first person

This one is the ground-truth engine, ported to JavaScript: the same block types, the same 8 yaws and 5 pitches, the same reach-4 raycast, the same gravity-and-step-up rule. It is here because the view-changing substrate has to be felt to be understood — occlusion is real, so what you see is a genuinely many-to-one function of the world state, and turning changes which part of the world's randomness reaches you. A single viewpoint receives 30.07% of it; an agent can move that number by 0.3125 just by looking around.

controls

space jump · G dig · H place · N new world

Digging changes what other agents see. That second-order path — your hole lets someone else's ray reach a different block — is exactly what a collision-counting metric misses, and why the project measures contention by replaying each tick with one agent acting instead of counting shared targets.
